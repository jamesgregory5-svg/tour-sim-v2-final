# Tour Sim v2 Final

Tour Sim v2 (v2.2.3), a WebGL golf simulator. Play: https://jamesgregory5-svg.github.io/tour-sim-v2-final/

## Features
- **Password gate** when the page opens (remembered for the browser session only).
- **Customization menu:** ball color (white, yellow, orange, red, blue, pink, black), ball trail (on/off, length, color) and a hole explosion effect.
- **Tournament mode:** 4 rounds and 72 holes on any course against 39 computer golfers. The field's strength follows the difficulty and your recent scores. Standings after each round, and a champion screen if you win.
- **30 courses**, including the new TPC Sawgrass (Stadium Course), St Andrews (Old Course), Bethpage Black and Five Ponds Golf Club.
- **Cart Part Only: Cart Chase.** Race CPU golf carts over 3 laps on 4 made-up tracks: Fairway Oval, Pine Twister, Lakeside Loop and Clubhouse Hairpins. Pick a cart color, choose one of the six difficulty levels (Reggie to Woods), and use the horn. Your best lap is saved for each track.
- Six swing difficulty levels, records, saves and settings carry over from v1. Saves are stored in this browser for this site.

The offline single-file copy is attached to the "Tour Sim v2 Final" release.
